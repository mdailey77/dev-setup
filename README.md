# dev-setup

This repository is for creating a DevOps-focused development setup on a local machine.

## vscode

The `vscode` folder contains recommended Visual Studio Code settings, keybindings and extensions, `settings.json`, `keybindings.json` and `extensions.txt` respectively.
There is an install script that will add a git pre-commit hook for linting along with adding the VS Code settings.

## homebrew-weekly-updater

The `homebrew-weekly-updater` folder contains Bash scripts that will install a launch agent to perform automated weekly updates of Homebrew packages.
